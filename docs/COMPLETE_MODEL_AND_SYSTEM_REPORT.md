## 1. Executive Summary & Impact
Satellite operators in Low Earth Orbit (LEO) receive hundreds of weekly conjunction alerts from public CelesTrak TLE feeds. Because TLE error margins expand rapidly past 24–48 hours, **over 95% of public collision alerts are false alarms**.

This platform solves **False Alarm Fatigue** through:
1. **Mathematical Physics ($\sigma_{DSE}$ & $P_c$):** Real-time isotropic covariance expansion scaling with Days Since Epoch (DSE).
2. **Pre-Trained Machine Learning Models:** Multi-model novelty detection verifying whether kinematic outliers warrant emergency maneuvers.
3. **Quantified Financial ROI:** Directly preventing unnecessary thruster maneuvers, saving approximately **$\$86,400\text{ USD}$** in propellant across 114 screened encounters.

## 2. Pre-Trained Machine Learning Model Analysis

| Model | Architecture & Configuration | Key Role in Pipeline | Catalog Anomaly Detection Rate |
| :--- | :--- | :--- | :--- |
| **Isolation Forest** | 300 Decision Trees, Contamination = 0.02 | High-velocity orbital drift outlier isolation | Flags kinematic anomalies |
| **One-Class SVM** | Radial Basis Function (RBF) Kernel, Standard Scaler | Non-linear geometric safety perimeter definition | Identifies envelope breaches |
| **Local Outlier Factor (LOF)** | 20 K-Nearest Neighbors, Novelty = True | Density-based reachability distance scoring | Clustered fragmentation debris detection |

### Feature Space Matrix
All models are evaluated over 5 physical orbital dimensions:
* `miss_distance_km`: Spatial distance at closest approach ($0.01\text{ to }15.0\text{ km}$).
* `time_to_approach_hours`: Time remaining until the conjunction plane is intersected ($0.1\text{ to }24.0\text{ hours}$).
* `data_age_hours`: Elapsed time since TLE observation epoch ($0\text{ to }400+\text{ hours}$).
* `relative_velocity_kms`: Relative kinetic approach speed ($1.0\text{ to }18.0\text{ km/s}$).
* `object_classification`: 0 (Payload), 1 (Rocket Body), 2 (Known Debris), 3 (Foreign/Unknown).
